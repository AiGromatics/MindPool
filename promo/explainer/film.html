MindPool is a VS Code extension that syncs your team’s skills from a private Git repository. Nothing is published to the web.

An open source extension by AIgromatics

Every teammate has a different copy.

Skills get edited, forgotten and left behind. And publishing your team’s skills to the open web isn’t an option.

Keep them in one private Git repository.

Its skill.json lists the skills your team shares, like dependencies in a package.json.

acme/team-skills/ skill.json
Step

Choose a pool folder.

Fill in the repository URL and branch, then Save & clone. MindPool writes config.json for you.

It clones the repo and installs every skill.

Each skill is downloaded with Git into mindSkills/, a folder that is never committed. Only the team settings get pushed.

Then it keeps everything in sync.

Each sync pulls the team’s new commits and installs newer skill versions. You don’t have to do anything.

MindPoolsyncs when

Each skill updates the way you choose.

Track a branch, pin a release tag, or follow a semver range that upgrades by itself.

Ranges work like npm’s: ^1.2.0, ~1.2, >=2 <3, 1.x

Your edits are never overwritten.

A skill with local changes stays exactly as it is. You decide whether to Reinstall.
